# Tekbyt Location Leads (WordPress Project) Custom WordPress theme and plugin for dynamic location-based lead generation. --- ## Developer Saqib Sajjad --- ## Project Includes * Custom WordPress Theme * Custom Plugin: tekbyt-location-leads * Custom Post Types (Locations, Services, Leads) * AJAX Lead Form * CRM API Integration * Admin Dashboard Widget --- ## Structure ```text wp-content/ ├── themes/ │ └── tekbyt-theme/ └── plugins/ └── tekbyt-location-leads/ ``` --- ## Setup 1. Copy project into WordPress `/wp-content/` 2. Activate theme from Appearance → Themes 3. Activate plugin from Plugins menu 4. Flush permalinks --- ## Plugin Features * Custom Post Types * Lead form with AJAX submit * Data sanitization and validation * CRM API request (httpbin) * Admin leads dashboard --- ## Testing * Check CPTs in admin panel * Submit lead form * Verify lead entry in admin * Check API sync status --- ## Notes No page builders used. Fully custom WordPress development.
